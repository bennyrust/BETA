# Consumption Log photographic pages

Extracted from the ten `log N-M copy.jpg` sheets in the parent directory. Each sheet is read left to right, top row then bottom row (four per row). No handwriting or punch holes were generated. Original paper colour, six punch rims, and photographic detail are retained; background outside the paper and inside its punches is masked to transparency. `extraction.json` records source order and measured corners.

Full images are lossless WebP; small grid thumbnails use the same alpha mask. The existing 8-row, 10-column grid and interactions are preserved. Original `individual pages` assets are retained.
